🔴⚪ Spartak Family — доступ к фото

Это публичная тестовая страница на GitHub Pages. Она пробует запросить через VK Bridge разрешение photos для приложения 54814503.

Никогда не отправляйте токен и не публикуйте скриншоты с ним. Не загружайте .env в GitHub. Эта страница не размещает посты, не загружает фотографии и не сохраняет токен на сервере GitHub Pages. Библиотека VK Bridge загружается с внешнего CDN unpkg.com.

Ожидание VK Bridge…

VK вернул пользовательский токен. Выданные права: не указаны.

Скопированный токен вставьте только в VK_USER_TOKEN= локального файла .env. Не отправляйте его в чат и не сохраняйте в облаке. После этого запустите check_photo_access.bat — он ничего не публикует.

Независимо от результата сохраняйте VK_AUTO_PUBLISH=0. Токен остаётся в памяти открытой вкладки до её закрытия и не записывается в cookies или localStorage этим кодом. Скрипт VK Bridge загружается из npm через unpkg.com; используйте страницу только для тестирования, не для хранения секретов.
