● ⚪ Spartak Family — проверка загрузки

Эта страница проверяет, разрешает ли VK API получение адреса сервера для загрузки фотографии на стену сообщества 212502839.

Безопасная проверка: токен не показывается и не копируется, фотографии не загружаются, записи не публикуются. Используется только метод photos.getWallUploadServer.

Тестовая страница публична на GitHub Pages. VK Bridge загружается из unpkg.com. Не используйте эту страницу для хранения токенов.
