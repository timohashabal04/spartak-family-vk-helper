Подключение вашей группы

Получите два доступа ВКонтакте и вставьте их в приложение на компьютере. Эта страница ничего не публикует.

1. Ключ сообщества

Для публикации записей от имени Spartak Family. Если ключ уже сохранён в Studio, повторно получать его не нужно.

2. Доступ к фотографиям

Нужен для загрузки фирменных карточек в группу. Запрашивается только разрешение photos.

3. Вернитесь в Studio

«Подключение группы» → вставьте ключи в соответствующие поля → «Сохранить ключи» → «Проверить подключение».

После успешной проверки можно включить автопубликацию. При истечении доступа Studio остановит отправку и попросит обновить ключ.
